## Phase 1 · Mechanism

**Hypothesis (tail collapse):** under total IMU loss the estimator stops receiving corrections, so the
proposer (L4) and the twin (L5) both read the same smooth, self-consistent estimate; their disagreement
keeps its typical size but loses its large excursions, so the score rarely crosses the threshold.

| test | measurement | supports the hypothesis if |
|---|---|---|
| T1 | Upper quantiles (90/95/99 %) and variance of `departure` and of the score, faulted vs clean | Upper quantiles and variance fall while the median stays ≈ 1.00 |
| T2 | Variability of the L2 estimate itself (tick-to-tick change) | Falls after onset |
| T3 | Dose–response across dropout 25 / 50 / 75 / 100 % | Monotone or threshold-like, consistent with C1b |
| T4 | Intervention: feed the twin an estimate from an independent path (benchmark-only, no `src/` change) | Alarms return |

Rule fixed before running; dev seeds `20260731+i`, then held-out once on **new** seeds (`20270101+i`),
because `20261201+i` has now been used by Stages A and C1b.

## Phase 3 · Harm and baselines

- **Harm (pre-registered):** time in NOMINAL while the gate is silent; true tracking error; time to a
  safer mode. Report censored runs explicitly.
- **Baselines:** L1-only, KS(conf) with its sequential-test bug fixed, conformal test martingale,
  Amoukou et al., D3M, oracle. One L1 definition used throughout (reconcile 12/30 vs 30/30 first).
- Run the missing `lateral_noise` arm from Stage C1.
- **Stretch — lying sensor (O6):** largest bias that evades every layer.

## Phase 4 · Stage D

1. ADR: when flagged blind, L6 **abstains** (ADR-0016 path); L8 stays gate-agnostic (SI-3).
2. Three arms, pre-registered, fresh held-out seeds: **no monitor / act on L1 / act on G2**.
3. Metrics: Safety Gain, Residual Hazard, Availability Cost; time in NOMINAL while faulted.
4. **Decision rule:** G2 is a contribution only if it beats "act on L1" on a pre-registered metric.
   Otherwise the paper recommends cross-layer health as the trigger and says so plainly.
