      Solid car = the real car. Blue outline = where ASTRA believes the car is. Glow under the car = driving mode. Red lamps = braking; blinking amber = stopped.
      Target behaviour is a hand-written illustration of what ASTRA is designed to do. It is not a run of the code and proves nothing; it is the specification the project is working towards.

      What the code does today is recorded output of the ASTRA pipeline: 120 s per run at 20 ticks per second, one run per case, seed . "Dormant features on" runs switch on parts that every experiment so far leaves off. These are single, exploratory runs, not evidence: a different seed can end differently.

      Purple means "no objection, but its picture is wrong". The page adds it by comparing ASTRA's estimate with the simulator's ground truth, which ASTRA never sees.
