      Solid car = the real car. Blue outline = where ASTRA believes the car is. Glow under the car = driving mode. Red lamps = braking; blinking amber = stopped.
      What this is. Recorded output of the ASTRA pipeline: 120 s per run at 20 ticks per second, one run per defect, all with the same seed (). Speeds, positions, modes, gate verdicts and L1 flags are the recorded values. Purple is added by this page by comparing ASTRA's estimate with the simulator's ground truth, which ASTRA itself never sees.

      What this is not. Evidence. It is one run per defect, not pre-registered. A different seed can end differently — in the 30-run studies, a frozen sensor led to a stop in about a third of runs and not in the rest.
